# GolfHub Perth

Find public golf tee times around Perth, with North/South filters, course information, scorecards and course maps.

## Download for Windows

**[Download the latest GolfHub installer](https://github.com/Jarryd22/golfhub-perth-updates/releases/latest)**

[Release notes and all versions](https://github.com/Jarryd22/golfhub-perth-updates/releases)

Download the `.exe` from the latest release and run it on your Windows 10/11 64-bit laptop. Finish any booking and close GolfHub before installing. If you already have GolfHub, install over the existing copy.

## Future updates

GolfHub 5.1.11 and later include an **Updates** button and optional checks when the app starts. When a newer stable release is available, select **Update available**, download it, then select **Install and restart**.

No GitHub account is required. Updates are announced inside GolfHub. The application verifies a signed release record and the downloaded installer before installation.

Versions are published only after the owner explicitly requests a release. Development and testing do not publish updates automatically.

This repository contains official installers and update records. You only need the `.exe`; `update.json` is for the application's update checker.
